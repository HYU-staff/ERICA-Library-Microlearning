# ERICA Library Microlearning

한양대학교 ERICA학술정보관의 도서관 활용 교육, 전자저널 소개, 연구자 이용 가이드 등을 모듈별로 제공하고 이용자의 신분과 수준에 맞는 교육 영상을 추천하는 웹사이트입니다.

## 주요 기능

- 이용자 신분·소속 기반 온보딩
- 신분과 이용 수준에 따른 맞춤 영상 추천
- 목적별 교육 영상 보관함과 영상 재생
- 한국어·영어 전환 및 다크 테마
- 관리자 통계, 이용자 열람 기록, 신규 영상 업로드
- 지정 관리자 이메일과 비밀번호 기반 관리자 로그인

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

배포용 빌드 확인:

```bash
npm run build
```
